# ROProj Starter

A minimal project scaffold for experimenting with Odipie.

## Setup

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

## Files

- `app.py` runs a small Odipie smoke check.
- `config.py` stores local example settings.
- `requirements.txt` installs Odipie from the parent checkout during local development.
- `docker-compose.yml` shows a project-level container entry point.
